Webhook Receiver
- Lives in the system tray after launch (Start Menu → NinjaWebhook Receiver)
- Listens on http://127.0.0.1:<listen-port> (default 5088; chosen during setup)
- Forwards to NT TCP 127.0.0.1:<tcp-port> (default 7077; chosen during setup; must match the listener panel)
- Logs: install folder → logs\receiver.log (Open logs from the tray menu)
- Discord webhook (if entered during setup) is saved in config.json → flow.discord_webhook_url

Flow Chrome extension
- Point Options / Futures webhooks to http://127.0.0.1:<listen-port>/signal
- See FLOW_TRADING.md

Options trade-receiver
- Optional URL and device API key are saved under config.json → options
- Options are sent only after the flow filter and futures order both succeed
- See OPTIONS_TRADING.md

Tunnel (TradingView)
- Use ngrok/cloudflare to https → http://127.0.0.1:<listen-port>
- See start-ngrok-tunnel.cmd and DISTRIBUTION.md
